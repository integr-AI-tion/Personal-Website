  • Using machine learning's logistic regression algorithm, I developed a model to predict students' university major choices based on their interests, activities, and influences. This project was initially made with the intention of knowing whether students' backgrounds and preferences effect their decision towards university majors.

    GitHub

  • Using machine learning's linear regression algorithm, I developed a model to predict students' scores based on their study hours and absence days. This project aimed to identify key factors that influence academic performance and provide insights for improvement.

    GitHub

The challenge involved optimizing the supply chain of a coffee company, KopiCompFest. We proposed CompFoods-X, an AI-powered recommendation system that optimizes delivery time, product distribution, and future business strategy.

    PDF File (Indonesian ver.)

    PPTX File (Indonesian ver.)

  • In this project, my teammate and I explored the synthesis of zinc oxide (ZnO) nanoparticles using tea leaf extract as a green reductant.
